| Символ                   | Описание                       | ASCII (Hex) |
|--------------------------|--------------------------------|--------------|
| `\\`                     | Обратная косая черта          | 0x5C         |
| `\'`                     | Одинарная кавычка             | 0x27         |
| `\"`                     | Двойная кавычка               | 0x22         |
| `\n`                     | Новая строка                  | 0x0A         |
| `\r`                     | Возврат каретки               | 0x0D         |
| `\t`                     | Горизонтальная табуляция      | 0x09         |
| `\b`                     | Стирание (backspace)          | 0x08         |
| `\e`                     | Экранирование                 | 0x1B         |
| `\f`                     | Перевод страницы              | 0x0C         |
| `\v`                     | Вертикальная табуляция        | 0x0B         |
| `\a`                     | Звуковой сигнал (bell)        | 0x07         |
| `\0`                     | Нулевой символ                | 0x00         |
| `\?                      | Вопросительный знак           | 0x3F         |
| `\xhh`                   | Шестнадцатичное число (hh)    | non-ASCII    |
| `\ooo`                   | Восьмеричное число (ooo)      | non-ASCII    |
| `\uXXXX`                 | Юникод (UTF-16)               | non-ASCII    |
| `\UXXXXXXXX`             | Юникод (UTF-32)                | non-ASCII    |
