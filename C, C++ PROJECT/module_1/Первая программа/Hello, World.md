Самый лучший способ изучить новый язык программирования — это сразу начать писать на нем программы. Программировать на любом языке по традиции начинают с такой задачи: вывести слова `Hello, World`.

Это не так мало, как кажется. Чтобы преодолеть этот этап, необходимо уметь подготовить код программы, успешно скомпилировать его и запустить выполнение, а затем выяснить, куда и как был выведен результат ее работы. 

На языке С программа для вывода `Hello, World` выглядит так:

```c
#include <stdio.h> // Включение информации о стандартной библиотеке

int main() // Определние функции main без аргументов 
{ // Операторы main заключаются в скобки
printf("Hello, World\n"); // Библиотечная функция printf выводит строку. 
} // \n означает переход на новую строку
```

Процесс компиляции этой программы зависит от системы, в которой вы работаете. Например, в операционной системе Unix необходимо поместить программу в файл, имя которого имеет окончание ==.с==. Например, hello==.с==. Затем ее следует скомпилировать с помощью следующей команды:
```bash
# Флаг -o отвечает за вывод скомпилированной программы в файл.
# Если его не указать, программа будет называться a.out. 
gcc -o myfirstprogram hello.c
```

Если не было сделано никаких ошибок, то компиляция пройдет без сообщений, и в результате будет создан выполняемый файл. Теперь этот файл можно запустить командой:

```bash
./myfirstprogram
```

В результате его выполнения будет выведена строка `Hello, World`. В других системах эта процедура будет отличаться. Обратитесь к **ВСТАВИТЬ СЮДА ГАЙД ПО НАСТРОЙКЕ ОКРУЖЕНИЯ НА РАЗНЫХ ОС** за подробностями.

Теперь рассмотрим саму программу. Программа на С независимо от ее размера состоит из **функций и переменных**. 

**Функция содержит операторы** — команды для выполнения определенных вычислительных операций, а в переменных хранятся числа и другие данные, используемые в этих операциях. 

В нашем примере функция имеет имя `main`. Обычно функциям можно давать любые имена по своему желанию, но `main`— особый случай, поскольку программа начинает выполняться именно с этой функции. Это означает, что в любой программе на С обязательно должна присутствовать функция main.

Обычно из `main` для выполнения разных операций вызываются другие функции, некоторые из которых программист пишет сам, а другие содержатся в стандартных библиотеках. 

В первой строчке программы содержится следующее:
```c
#include <stdio.h>
```

Это указание компилятору включить в программу информацию о стандартной библиотеке ввода-вывода. Эта же строка имеется в начале многих файлов исходного кода С. Один из методов передачи данных между функциями заключается в том, что одна функция вызывает другую и предоставляет ей список чисел, именуемых аргументами. Список аргументов заключается в круглые скобки и ставится после имени функции. В нашем примере `main` является функцией без аргументов, на что указывает пустой список в скобках.

Операторы функции заключаются в фигурные скобки. Функция main в данном примере содержит всего один оператор:
```c
printf("Hello, World\n");
```

Чтобы вызвать функцию, необходимо ввести ее имя, а затем список аргументов в круглых скобках. В нашем примере вызывается функция `printf` с аргументом `"Hello, World\n"`. Функция `printf` включена в стандартную библиотеку и выводит форматированный текст на экран. В данном случае это один аргумент в виде строки текста в кавычках и символ переноса строки.

Последовательность символов в двойных кавычках, такая как `"Hello, World\n"`, называется **символьной строкой** или **строковой константой**. В данный момент единственным применением таких строк для нас будет их передача в функцию `printf` и аналогичные функции вывода. 

Комбинация символов `\n` в строке является условным обозначением языка С для указания конца строки, который переводит вывод данных на новую строку. Если убрать `\n` (поэкспериментируйте для наглядности), то окажется, что после вывода символов переход на новую строку не произойдет. Чтобы включить такой переход в аргумент `printf`, необходимо воспользоваться комбинацией `\n`. Функция `printf` никогда не вставляет конец строки автоматически, поэтому одну строку можно составить из нескольких вызовов этой функции. 

Наша первая программа могла бы иметь и такой вид:

```c
#include <stdio.h>

main()
{
printf("Hello, ");
printf("World");
printf("\n");
}
```

Результат ее работы был бы тот же. Обратите внимание, что комбинация `\n` представляет один символ. Для обозначения всех символов, которые трудно или невозможно изобразить на письме, используются [[Управляющие последовательности | управляющие последовательности]] (escape sequences).
